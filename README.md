# Awesome-Document-Collaboration

# Top Document Collaboration Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Real-Time Co-Editing, File Sharing, Team Workspaces, Versioning & Secure Document Workflows*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Document Collaboration**. These tools enable teams to create, edit, share, and manage documents, spreadsheets, presentations, and knowledge bases in real time, with version history, permissions, commenting, and integration into broader productivity workflows.

**Examples** include Google Workspace, Microsoft 365, Dropbox DocSend, ONLYOFFICE, Zoho WorkDrive, Box, Egnyte, Nextcloud, Confluence, and Notion (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted office suites, real-time editors, encrypted collaboration, file sync & share, and open knowledge platforms — ideal for organizations seeking data sovereignty, privacy, and fully controllable document collaboration environments.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Google Workspace](https://workspace.google.com/)**  
  Cloud-native suite (Docs, Sheets, Slides, Drive) offering seamless real-time co-editing, sharing, version history, and deep integration across Google’s productivity ecosystem.

- **[Microsoft 365](https://www.microsoft.com/en-us/microsoft-365)**  
  Enterprise productivity platform with Word, Excel, PowerPoint, OneDrive, and SharePoint providing high-fidelity desktop + web co-authoring, governance, and Copilot AI features.

- **[Dropbox DocSend](https://www.dropbox.com/docsend)**  
  Secure document sharing and tracking solution focused on controlled external collaboration, analytics on viewer engagement, and professional content distribution.

- **[ONLYOFFICE](https://www.onlyoffice.com/)**  
  Online office suite with strong Microsoft Office format compatibility, real-time co-editing, and both cloud and self-hosted deployment options.

- **[Zoho WorkDrive](https://www.zoho.com/workdrive/)**  
  Team file management and collaboration platform with online editors, granular permissions, workflows, and tight integration into the Zoho ecosystem.

- **[Box](https://www.box.com/)**  
  Enterprise content cloud for secure file sharing, collaboration, governance, workflow automation, and extensive third-party integrations.

- **[Egnyte](https://www.egnyte.com/)**  
  Hybrid content collaboration and governance platform combining cloud and on-premises storage with advanced security, compliance, and multi-location access.

- **[Nextcloud](https://nextcloud.com/)**  
  Content collaboration platform (also available as fully open-source self-hosted software) offering file sync, sharing, collaborative editing, and groupware features.

- **[Confluence](https://www.atlassian.com/software/confluence)**  
  Team knowledge base and documentation platform tightly integrated with Jira, supporting structured pages, real-time editing, and enterprise knowledge management.

- **[Notion](https://www.notion.so/)**  
  Flexible all-in-one workspace combining documents, databases, wikis, and project tools with real-time collaboration and highly customizable pages.

## Open-Source GitHub Projects

- **[Nextcloud](https://github.com/nextcloud/server)**  
  Leading open-source content collaboration platform for file sync & share, real-time office editing (via connectors), Talk, Groupware, and full data control on your own servers.

- **[ONLYOFFICE Document Server](https://github.com/ONLYOFFICE/DocumentServer)**  
  Open-source online office suite providing collaborative editing of documents, spreadsheets, and presentations with excellent Microsoft Office format fidelity.

- **[Collabora Online](https://github.com/CollaboraOnline/online)**  
  LibreOffice-based open-source collaborative online office suite for real-time editing of ODF and Office formats, commonly integrated with Nextcloud.

- **[CryptPad](https://github.com/cryptpad/cryptpad)**  
  End-to-end encrypted, zero-knowledge collaboration suite offering real-time documents, spreadsheets, pads, and file storage where even the server cannot read content.

- **[Etherpad](https://github.com/ether/etherpad-lite)**  
  Lightweight, highly customizable real-time collaborative text editor ideal for meeting notes, collaborative writing, and simple shared documents.

- **[HedgeDoc](https://github.com/hedgedoc/hedgedoc)**  
  Open-source real-time collaborative Markdown editor (formerly CodiMD) for creating, sharing, and co-editing notes and documentation.

- **[Seafile](https://github.com/haiwen/seafile)**  
  High-performance open-source file sync and share platform with strong collaboration features and optional online editing integrations.

- **[ownCloud](https://github.com/owncloud/core)**  
  Open-source file sync, share, and collaboration platform focused on data ownership and extensibility.

- **[Tracim](https://github.com/tracim/tracim)**  
  Open-source collaboration suite combining file sharing, threaded discussions, collaborative pages, tasks, and workspace organization.

- **[Outline](https://github.com/outline/outline)**  
  Modern open-source knowledge base and team wiki with real-time collaborative editing and clean documentation workflows.

- **[AppFlowy](https://github.com/AppFlowy-IO/AppFlowy)**  
  Open-source Notion alternative for documents, databases, and team knowledge management with offline-first capabilities.

- **[AFFiNE](https://github.com/toeverything/AFFiNE)**  
  Open-source collaborative workspace combining docs, whiteboards, and databases with a focus on privacy and local-first design.

### Additional Strong Open-Source Options

- **LibreOffice Online / Collabora CODE** for desktop-aligned collaborative editing.
- **Markdown-centric tools**: HedgeDoc, CodiMD forks, Foam, and Obsidian-style community plugins for shared knowledge.
- **File sync & share**: Syncthing (P2P), Seafile, and Nextcloud ecosystem apps.
- **Wiki & knowledge platforms**: Wiki.js, BookStack, Outline, and DokuWiki with collaboration extensions.
- Many community **real-time CRDT editors**, **ProseMirror/Yjs**-based tools, and privacy-focused pad projects.

**Frameworks for building custom systems**: Combine **Nextcloud** (or Seafile/ownCloud) for file management and permissions, **ONLYOFFICE or Collabora Online** for office document editing, **CryptPad or Etherpad/HedgeDoc** for secure or lightweight text collaboration, and open wiki tools for a complete self-hosted document collaboration platform.
